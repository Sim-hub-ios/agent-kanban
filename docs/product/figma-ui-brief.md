## 已确认交互，不回退

以下为设计依据和产品交互约束，不表示 Figma 已实现全部业务逻辑或状态；窄屏规则保留为后续适配依据，本轮 Figma 未制作窄屏。

- 桌面工作台保留看板与运行记录；普通会话归属项目，项目侧栏提供列表和新建。聊天内容顶部只读显示项目与当前会话名称，不设置会话切换下拉。
- 桌面全局侧栏底部放“执行器与认证”，打开轻量弹窗；项目“…”菜单只放移除等项目操作。桌面头部不重复放认证齿轮，窄屏无侧栏时保留头部齿轮；窄屏工作视图导航只有看板、会话、记录。
- 导入项目入口位于本机项目区、窄屏项目栏及无项目空态。取消“已移除项目”与“重置演示”入口及整个项目恢复功能；场景 16 在 Figma 隐藏停用并清除全部入出连线，图库不展示。移除确认展示项目名、路径与关联记录影响，不删除仓库、代码、分支或 worktree，也不要求永久删除内部存储。同目录可重新导入为新的项目记录，不承诺恢复原 ID 或历史数据。运行、停止屏障或 Skill 导入中阻止移除；最后一个项目可移除，刷新保持空态。
- 输入框采用 Codex 式布局：上方输入文字，下方工具栏；左侧附件和盾牌权限入口，右侧单一紧凑“执行器 · 模型 · 强度”摘要与发送/停止操作。推理强度按语义值从冷蓝逐级过渡至紫色，点击摘要先打开一级紧凑推理面板；含闪电、中部可点击的强度/默认或当前模型名/chevron、重置和下方滑杆。初始直接使用执行器默认模型，点击中部模型名才进入二级执行器/模型列表，选模型返回一级更新摘要，不常驻并排显示列表与滑杆。
- 执行器限 Codex、Claude、Cursor。模型显示已核对的精确版本；Cursor 主列表为 Auto、Grok 4.7、Composer 2.5，Auto 不编造版本。实际模型与合法强度以对应目录为准，可参考 `model-selection-helpers.js` 及 `research/` 记录，不能给每个模型套相同强度。
- 一级推理面板使用 Codex 式随强度变色的离散滑杆，中部模型入口同时居中显示当前强度与默认/当前模型名，提供重置；滑杆起点为“默认”自动状态，其后仅当前模型合法档位；默认表示未显式覆盖，不是额外强度等级。重置清除显式覆盖、恢复执行器默认。无独立强度能力时禁用并说明，不把默认模式伪装成等级；支持方向键、Home/End 与可访问值文字。不用强度分段按钮/下拉，也不进入新建任务表单。
- 权限菜单只有“请求批准 / 帮我批准 / 完全访问权限”三行。不可用项禁用并简短解释；默认未知或已有自定义组合不伪造勾选。不增加沙箱/审批/审批方多字段表单或高级入口；同名预设不代表三个执行器边界相同。
- 新建任务仅填写任务内容与类型/优先级，自动采用当前项目默认执行器及其原生默认模型、强度与权限，不复制来源聊天配置。后续在任务主会话底栏调整；项目默认变更不覆盖已有任务，不新增项目默认模型或设置页面。
- 新建任务“说明与备注”为可编辑多行文本框，支持 Enter 换行、多行粘贴和纵向调整高度，保存及显示保留段落与换行，Enter 不提交创建。
- 所有任务（含 Skill 导入任务）执行目录固定为所属项目 `project.path`，不提供每任务工作区或 worktree 选择；隔离跟随执行器原生沙箱与权限，同目录写入串行。历史 Run 的 cwd 与证据保留原值，不声称已迁移旧会话或进程。
- 会话与任务分别保存执行配置；切换后恢复，修改只对下一次回复/Run 生效。历史回复和旧运行保留原快照，未知的实际生效状态不标成已确认或已沙箱。
- 普通项目会话可以按当前原生权限直接读改代码、运行命令，无需先建任务；审批、停止、恢复和快照归属 Conversation，与任务共享目录写入锁。仅明确要求转任务或导入时才创建看板任务。任务的讨论/验收阶段继续只读，阶段推进与完成由人操作。
- 任务清单导入是聊天中的内置 Skill：通用附件或 Issue 链接加明确导入指令后直接创建待处理任务，在会话报告数量、重复与错误；不加专用按钮、导入向导、候选选择或统一确认，不自动启动新任务。
- 不恢复独立项目设置、Agent 配置、Providers 页面，也不恢复项目默认模型、预算或全局分析开关。

## 视觉与字体

视觉方向改为 macOS 26 Liquid Glass：导航、工具栏、输入控件与菜单浮层使用玻璃材质；正文、任务卡、代码与 diff 保持稳定、易读的内容底色。沿用细致灰阶、清晰层级和蓝色主操作，推理强度按语义值使用冷蓝至紫色阶梯；阶段和运行状态结合语义色、文字或图标表达。

筛选下拉使用独立 chevron 矢量图标；任务卡、会话执行摘要与认证列表等执行器身份统一使用对应标志，并保留名称。Codex 使用其官方文档中的 OpenAI Blossom，Claude 使用 Spark，Cursor 使用 Cube；来源见 [执行器图标记录](assets/executors/sources.md)。

Figma 采用可编辑的 GLASS effect、透明 RGBA 填充、高光与阴影，应用于导航、composer、popover 和 sheet；卡片正文及 diff 保持实底。这些设计效果不替代 SwiftUI 原生材质的光学行为。

原生实现须响应浅/深色、“减少透明度”“减少动态效果”和“增加对比度”，并在减少透明度时保留清晰实底和边界。Figma/HTML 仅模拟材质与代表性状态，不等于 SwiftUI 系统材质或系统无障碍设置实测通过。参考 Apple [Adopting Liquid Glass](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass) 与 [Materials](https://developer.apple.com/design/human-interface-guidelines/materials)。

本轮重新导出全部 20 个有效场景及 Components，视觉复核 01、10、11、13、14、15 与 Components：共享侧栏和空态无旧入口；移除弹窗不再承诺恢复；Ultra、High、Cursor Auto 分别显示紫色、靛色与中性禁用态，品牌图标、正文和操作未见裁切。全量可见节点结构检查确认旧入口为 0，恢复场景入出连线为 0，可见场景为 20，保留 3 个 flow。此前其余场景已完成静态视觉检查；先前记录的 9 处最大 3 px 未裁切容器边界提示未被本轮重做为零越界结论。

本次文件全部使用可渲染的 Noto Sans SC，文字保持可编辑。原型字体为 SF Pro / PingFang；Figma 字体列表虽列出 SF Pro，实际渲染为空且设置返回 `font unavailable`，PingFang 未提供，因此采用该 fallback。macOS 布局与主色沿用来源；SF Pro 不计为已验证可用字体。


推理颜色按语义强度映射，跨执行器相同强度使用同色，不按某个模型的合法档位数组下标截取色板。滑轨、闪电、当前强度文字与输入区 effort 标签保持一致；默认表示未覆盖原生策略，Cursor Auto / Composer 等无独立强度能力时使用中性禁用态。Figma 保留代表性静态档位，任意档位切换由 HTML 交互演示。

## 手动完成与原生输入补充

用户可从开发直接手动完成，无需先进入验收或产生报告。报告缺失、未通过、过期或需求/方案尚未确认均不阻止完成；有报告则保留原状态作参考。运行停止屏障、阶段并发和归属校验继续保留，Agent 不自动完结任务；完成不隐式提交、合并或发布代码。

创建/编辑任务的说明与备注、任务主会话及项目普通会话采用一致的原生输入控件。placeholder 与文本/caret 首行共用 TextKit 排版、字体与内容边距；中文 IME 产生 marked text 时立即隐藏，不等待文本绑定提交；仅文本清空且没有 marked text 时恢复。此处为规范补充，现有 PNG 与 Figma 云端图层未因本次文档修改而更新。
