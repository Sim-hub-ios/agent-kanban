导入本机项目

把已有代码库加入工作区，在项目下管理任务与会话。

产品实现将通过系统文件夹选择器授权目录。此 HTML 原型请手动输入路径。
仅演示导入流程。不会读取目录、验证 Git、克隆仓库或连接执行器。新项目的任务与会话从空状态开始。

删除会话

会话将从项目列表移除，已导入任务和来源记录保留。

删除当前会话后返回项目看板；运行或任务导入尚未结束时不能删除。

新建任务

任务从待处理开始，由你决定何时进入下一阶段。

原生输入规范：placeholder 与 caret 首行共用 TextKit 排版；中文 IME marked 期间立即隐藏，仅内容为空且无 marked text 后恢复，创建备注与会话一致。⌘V 可粘贴截图或 Finder 文件，显示缩略预览并可打开/移除；附件随任务保存。普通文件单项 25 MB，发送图片总量 5 MiB。此 HTML 保留静态附件说明，系统剪贴板与持久副本在 macOS 客户端验证。

待处理阶段只保存信息，不启动 Agent。普通聊天转来的建议也需由你确认创建。
